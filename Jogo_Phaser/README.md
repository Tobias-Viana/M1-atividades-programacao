O código utiliza Programação Orientada a Objetos (POO) por meio da herança, onde todas as cenas do jogo estendem (extends) Phaser.Scene, herdando seus métodos e propriedades. O encapsulamento é aplicado ao manter variáveis como this.score e this.hasKey dentro de cada classe, garantindo organização e controle sobre os estados do jogo. O polimorfismo aparece quando GameScene e GameScene2 redefinem (override) métodos como preload, create e update, mantendo a estrutura geral, mas com comportamentos diferentes. Além disso, o código cria diversas instâncias de objetos, como o jogador, inimigos e itens, atribuindo propriedades e comportamentos específicos a cada um. Essa estrutura modular melhora a organização, reutilização e manutenção do código.
